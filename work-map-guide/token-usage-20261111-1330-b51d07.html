토큰·비용 측정 (Langfuse 준비 1단계)

기록 시각 2026-11-11 13:30(KST) · 가지 claude/project-thread-mgqoqm · 사용자 검토 대기 — main에는 넣지 않았습니다. 작업 보고 스킬(work-map-guide)이 이 환경에 없어 같은 형식으로 직접 작성했습니다.

한 줄 요약

모델을 부를 때마다 Hermes가 세는 입력·출력 토큰과 추정 비용을 받아서, 노드 기록·분석 결과·평가 요약에 채우고 화면에 보여 줍니다. 모르는 값은 0이 아니라 "미측정"으로 남깁니다.

바뀐 것

  • server/role_runner.py: 호출이 끝난 뒤 Hermes 에이전트의 session_input_tokens 등 카운터를 읽어 usage로 돌려줍니다. 카운터가 없거나 0/0이면 None입니다. 비용 상태가 unknown이면 비용 숫자를 쓰지 않습니다.
  • server/chains.py: 사용량을 LangChain 표준 usage_metadata에도 넣고, 노드 완료 기록(triage·draft·critic)에 토큰·비용을 채운 뒤 실행 전체 합계 tokens·cost_usd를 계산합니다. 보안 차단으로 모델을 부르지 않은 노드는 "모델 호출 없음"으로 구분합니다.
  • server/pipeline.py는 고치지 않았습니다. 버전 판정이 이 파일 글자로 지문을 만들기 때문입니다.
  • server/evaluations.py: 평가도 같은 경로로 실행해 token_count·cost_usd를 집계합니다. 한 사례라도 모르면 합계는 None입니다.
  • 화면(OperationsConsole): 노드 상세의 "토큰: 미측정 · 비용: 미측정" 고정 문구를 실제 값으로, 평가 요약 카드도 실제 합계로 바꿨습니다.

검증

  • 서버 pytest 103개 통과(로컬 PostgreSQL 16), ruff format 검사 통과.
  • 화면 vitest 26개, 브리지 5개 통과, mock 빌드 성공.
  • 실제 Hermes 컨테이너로는 실행하지 않았습니다. Hermes 최신 소스 기준으로 카운터 이름을 확인했고, 설치된 버전에 카운터가 없으면 지금처럼 "미측정"으로 나옵니다.
