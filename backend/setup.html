도구 연결 준비

개인 Gmail · 로컬 Hermes 모델 · 자비스 전용 저장소

현재는 연동 준비 단계입니다. 메일 자동 처리와 발송은 실행되지 않습니다. Hermes 연결 확인은 짧은 테스트 문장으로 모델을 한 번 호출합니다.
연결 상태를 확인하고 있습니다.

계정 설정이 필요한 항목
  1. Gmail: Google Cloud에서 Gmail API를 사용 설정하고 데스크톱 앱 OAuth 클라이언트를 준비합니다. 개인 계정으로 동의한 뒤 연결 확인을 누릅니다. 이 앱은 조회와 초안 생성만 구현하며 발송 기능은 제공하지 않습니다. Google의 compose 권한 자체는 발송 권한도 포함합니다.
  2. LangSmith: 사용할 프로젝트와 API 키를 서버의 로컬 설정에 넣습니다. 키를 채팅에 붙여넣지 마세요. 현재는 메일 원문이나 초안이 LangSmith로 전송되지 않습니다.
