# 회사에 다니면서 위젯 10개를 움직이는 쉬운 계획

> 최종 목표: 내일 회사 일을 지키면서 위젯 후보 10개를 Javis 작업 카드로 준비하고, 첫 위젯 1개가 보고서 → 통과 → 제작 → 검사 → PR까지 끝나는 길을 확인한다.

## 핵심 한 줄

내일의 숫자 10은 **완성 위젯 10개**가 아니라 **추적 가능한 작업 카드 10개**다. 실제 제작은 한 번에 1개만 진행하고, 첫 번째가 끝까지 통과한 뒤 다음 위젯을 시작한다.

## 3줄 줄거리

1. 휴대폰 Javis 설치와 MIMO 작업 전 보고서 통과까지는 완료됐다.
2. 아직 Javis 통과 뒤 A01·A03의 제작과 PR까지 자동으로 이어졌다는 기록은 없다.
3. 내일은 후보 10개를 준비하되, MIMO 상품 카드 1개로 전체 길을 먼저 확인한다.

## 지금 위치

전체 목표 `52개 후보를 자산으로 만들기` → 현재 파트 `첫 위젯 시험` → 현재 지점 `Javis 통과 뒤 제작 시작을 연결하기`.

|---|---|---|

|MIMO 첫 보고서|보완 필요|처음 보낸 내용은 범위가 맞지 않아 다시 작성해야 했다.|

## 내일의 안전한 목표

### 반드시 끝낼 것

- 후보 10개를 각각 다른 작업 카드로 만든다.
- 모든 카드에 보여줄 내용, 눌렀을 때 할 일, 하지 않을 일을 적는다.
- MIMO 상품 카드만 첫 제작 대상으로 둔다.
- MIMO 결과에서 화면, 검사 결과, PR 주소를 받는다.
- main 병합과 운영 배포는 사용자 확인 전에는 멈춘다.

### 시간이 남으면 할 것

- 첫 위젯이 통과한 뒤 두 번째인 KMovement 장소 카드의 작업 전 보고서를 검사한다.
- 같은 실수가 반복되면 10개 카드의 공통 문구만 한 번 고친다.

### 내일 하지 않을 것

- 10개를 동시에 제작하지 않는다.
- 회사 근무 중 계속 Javis를 들여다보지 않는다.
- 화면만 보이는 것을 완료라고 세지 않는다.
- PR 없이 main 병합이나 운영 배포로 넘어가지 않는다.

## A01에게 보낼 요청문

> 내일 목표는 위젯 10개를 한꺼번에 완성하는 것이 아닙니다. 후보 10개를 각각 추적 가능한 작업 카드로 만들고, 한 번에 1개만 제작하세요. 먼저 Javis에서 통과된 MIMO 상품 카드 보고서 v1.1을 사용해 A03이 코드 수정, 검사, 화면 증거, PR 작성까지 진행하게 해주세요. main 병합과 운영 배포는 멈추고 저에게 알려주세요. 첫 위젯이 통과하기 전에는 두 번째 위젯을 제작하지 말고, 나머지 9개는 작업 전 보고서 준비까지만 진행하세요. 출근 중에는 제 답을 기다리지 말고 범위 안의 일을 진행하되, 범위 밖 결정이나 사용자 확인이 필요한 일만 질문하세요.

## Javis에서 볼 것

1. **위젯 작업**을 연다.
2. MIMO 보고서가 **통과**인지 확인한다.
3. 다음 상태가 `A01 접수`, `A03 작업 중`, `검사 완료`, `PR 준비`처럼 이어지는지 본다.
4. `사용자 확인 필요`가 아니면 회사 근무 중에는 닫는다.

현재 Javis에는 수집과 통과 기록만 확인됐다. 이후 단계가 화면에 나타나기 전에는 자동 연결이 끝났다고 보지 않는다.

## 완료 기준

### 첫 위젯 완료

- MIMO 상품 카드의 실제 실행 화면이 있다.
- 비어 있음, 사진 없음, 긴 제목, 좁은 화면을 확인했다.
- 눌렀을 때 맞는 상품을 한 번만 연다.
- 검사 결과가 통과했다.
- PR 주소가 있다.
- main 병합과 운영 배포는 사용자 확인 대기다.

## 아직 모르는 것과 확인 방법

**아직 모르는 것:** 첫 위젯 한 개가 통과부터 PR까지 얼마나 안정적으로 이어지는가.

**확인 방법:** MIMO 한 개만 끝까지 진행해 빠진 단계, 되돌아온 횟수, 사용자에게 질문한 횟수를 기록한다. 이 한 개가 통과한 뒤에만 두 번째 제작을 시작한다.

**판정:** 현재는 일부 확인. Javis 검토 통과까지는 확인됐고, 제작·검사·PR 자동 연결은 아직 확인되지 않았다.

## Before / After

**Before — 현재 확인:** 보고서가 Javis에서 통과했지만 그 뒤 제작 접수와 PR 결과가 이어졌다는 기록은 없다. 사용자가 진행 상황을 직접 기억해야 한다.
