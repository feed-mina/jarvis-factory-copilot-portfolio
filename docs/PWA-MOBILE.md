# Javis 휴대폰 앱 설치

Javis는 별도 앱스토어 설치 없이 휴대폰 홈 화면에 추가하는 PWA로 사용할 수 있습니다.

## Android Chrome 또는 Samsung Internet

1. `https://jarvis.example.com/widget-work`를 엽니다.
2. 허용된 Google 계정으로 로그인합니다.
3. 화면 위의 **앱 설치** 버튼이 보이면 누릅니다.
4. 버튼이 없으면 브라우저 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
5. 홈 화면의 **Javis** 아이콘을 눌러 실행합니다.

설치 앱은 `/widget-work`에서 시작합니다. 위젯 작업과 에이전트 실행 바로가기를 제공합니다.

## 캐시와 로그인 경계

- Gmail·작업 API와 Google 로그인 경로는 캐시하지 않습니다.
- 화면 이동 요청도 캐시하지 않아 로그인 상태를 서버에서 매번 확인합니다.
- 아이콘, manifest와 해시가 포함된 정적 화면 자산만 캐시합니다.
- 인터넷이 끊긴 상태에서 메일이나 작업 데이터를 보여주는 오프라인 앱은 아닙니다.

## PWA 로그인과 CSRF 오류

PWA를 처음 열거나 업데이트할 때 시작 화면, 서비스 워커와 manifest 요청이 가까운 시각에 발생할 수 있습니다. 웹 로그인 프록시는 각 OAuth 흐름에 서로 다른 서명된 CSRF 쿠키를 사용하며, 중단된 흐름의 쿠키가 무한히 쌓이지 않도록 개수를 제한합니다. 로그인 세션이 끝난 화면의 API 폴링은 새 OAuth 흐름을 만들지 않고 `401`로 중단됩니다. 기존 `Secure`, `HttpOnly`, `SameSite=Lax` 속성과 허용 계정 검사는 그대로 유지합니다.

`Unable to find a valid CSRF token`이 보이면 다음 순서로 다시 시작합니다.

1. 오류 callback을 새로고침하지 말고 PWA와 같은 사이트의 브라우저 탭을 모두 닫습니다.
2. 홈 화면의 Javis 아이콘을 다시 열어 시작 주소에서 새 로그인 흐름을 만듭니다.
3. 허용된 Google 계정 하나를 선택하고 15분 안에 로그인을 마칩니다.
4. 계속 실패하면 전체 callback URL, `code`, `state`, 쿠키는 공유하지 말고 오류 문구, Request ID와 발생 시각만 운영 담당자에게 전달합니다.

로그인 프록시 설정을 갱신한 직후에는 이전 설정에서 시작한 callback이 한 번 실패할 수 있습니다. 이전 callback을 재사용하지 말고 반드시 PWA 시작 화면에서 다시 로그인합니다.
