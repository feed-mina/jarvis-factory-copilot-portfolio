## 4. 수정 또는 확인 방법

1. 검수 결과에 실행 모드와 작업 version을 기록합니다.
2. 모의 API에서 pending_review, approved, dirty, save_uncertain 상태를 각각 확인합니다.
3. 실제 Gmail 검증은 별도의 허가된 테스트 계정에서 초안 생성 여부로 판정합니다.

## 5. 완료 기준

- [ ] dirty=true이면 승인·저장 버튼이 허용되지 않습니다.
- [ ] approved 상태에서 저장 요청에 현재 version이 포함됩니다.
- [ ] 초안 저장 완료를 메일 발송 완료로 표시하지 않습니다.

## 6. 검증 방법과 제출할 근거

상태별 actions 반환값과 요청 본문을 확인합니다. 외부 검증은 테스트 계정·작업 ID·초안 ID만 비밀값 없이 남기며, 현재 보고서에서는 미실행으로 유지합니다.

실행 결과·캡처·응답 본문 중 완료 기준에 해당하는 근거를 남깁니다. 미실행 항목은 완료로 표시하지 않습니다.
