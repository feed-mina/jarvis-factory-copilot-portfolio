# Project working instructions

## Completion reports (user request, 2026-09-13)

After each completed task, use the `work-map-guide` skill and provide a new standalone HTML report in this project's `work-map-guide/` folder. Use a timestamp and unique suffix; preserve previous reports. Include what changed, evidence and validation, unfinished steps and the user's next action. Ongoing evaluation is not completion; clearly label snapshot time and pending user review.

This convention also applies when another agent or product works on this project and can read these instructions. If the skill is unavailable, explicitly state that limitation and preserve a progress record without falsely claiming to have used it. Reports do not authorize commits, pushes, deployment or user approvals. Follow explicit task-specific user overrides.
